Resumen de cambios
FEED-001 — Excluir recetas propias del feed
BE: FiltrosFeed acepta excluirPropio, el repositorio aplica { autorId: { $ne: userId } } cuando se activa
FE: feedHome.tsx pasa excluirPropio: true → solo activo cuando hay sesión activa
LIKE-001 — Like persistente
FE: tarjetaPost.tsx ahora usa useToggleLike + useToggleGuardado con optimistic update y rollback en error. La cabeceraReceta ya lo usaba, ahora también lo hace la tarjeta del feed.
COM-001 — Comentarios persistentes
BE: Nuevo endpoint POST /api/recetas/:id/comentarios → guarda en listaComentarios del documento
FE: comentariosReceta.tsx tiene textarea + botón publicar + hook useAgregarComentario. Los comentarios se añaden localmente al instante y se persisten en BD. Muestra "Sé el primero en comentar" si está vacío.
SOC-001 — Botón Seguir/Dejar de seguir
BE: Schema Usuario tiene seguidos[] y seguidores[]. Nuevo endpoint POST /api/usuarios/:id/seguir (toggle)
FE: cabeceraReceta.tsx muestra botón Seguir/Siguiendo junto al avatar del autor. Se oculta en recetas propias. El estado sigueAlAutor viene del backend y se refleja en todas las respuestas de recetas.
Prueba con npm run dev en ambos lados y dime qué ves al cargar /recetas/[id].
