Completar Perfil — Documentación técnica

Ruta: /completar-perfil  ·  Sprint: 2  ·  Estado: 👁️ Pendiente revisión  ·  Última actualización: 2026-04-12

Propósito Vista de onboarding post-registro. El usuario selecciona sus alergias/intolerancias y preferencias de dieta para personalizar su experiencia en Cookr. Se muestra una sola vez tras el registro. Los datos se guardan en el perfil del usuario (mock hasta Fase 5).

1. Arquitectura de capas

page.tsx (Server Component — /completar-perfil)
  └─ FormularioCompletarPerfil (Client Component — features/auth/components)
       ├─ SelectorChips (componente reutilizable — components/common)
       └─ ALERGENOS_OPCIONES, DIETAS_OPCIONES (config estática — config/opcionesUsuario.ts)

La ruta está fuera del grupo (main) — no tiene NavBarInferior. Es un flujo de onboarding independiente, igual que /registro o /login.

2. Ficheros del módulo

Fichero Tipo Responsabilidad
src/app/completar-perfil/page.tsx Server Component Shell de ruta. Importa y renderiza FormularioCompletarPerfil. Define metadata.
src/features/auth/components/formularioCompletarPerfil.tsx Client Component Estado de selección (alergenos, dietas). Orquesta la pantalla completa. CTA "Listo" → router.push('/home').
src/components/common/selectorChips.tsx Client Component (reutilizable) Selector múltiple por chips. Animación Framer Motion. Límite opcional (max).
src/config/opcionesUsuario.ts Config estática Fuente de verdad de las 14 opciones de alérgenos y 12 de dietas.

3. Componente SelectorChips

Componente genérico de selección múltiple por chips. Pensado para reutilizarse en:

  • /completar-perfil — alérgenos y dietas (onboarding)
  • /ajustes — modificar preferencias (Sprint 7)
  • Filtros de búsqueda de recetas (Sprint 3)

Props

interface PropsSelectorChips {
  opciones:      readonly OpcionChip[];   // { id, label, icono? }
  seleccionados: string[];            // IDs activos (estado en el padre)
  onChange:      (sel: string[]) => void;
  max?:          number;              // límite opcional
}

Comportamiento

  • Chip inactivo pulsado → se añade al array seleccionados.
  • Chip activo pulsado → se elimina del array.
  • Si max definido y alcanzado → chips inactivos quedan deshabilitados (opacity-40 cursor-not-allowed).

Estilos

EstadoClases Tailwind
Inactivo bg-muted text-muted-foreground border border-border rounded-full px-3 py-1.5 text-sm font-medium
Activo bg-brand text-brand-foreground border border-brand rounded-full px-3 py-1.5 text-sm font-medium
Deshabilitado opacity-40 cursor-not-allowed (sobre estilos inactivo)

Animación

Al activar un chip: scale([1, 1.05, 1]) vía Framer Motion, duration: 150ms. Al pulsar (whileTap): scale(1.05).

Iconos

Si la opción tiene icono (ruta string), se renderiza con next/image a 16×16 px. Las imágenes de alérgenos están en /public/alergenos/*.webp. Las dietas no tienen icono.

4. Config — opcionesUsuario.ts

Ubicado en src/config/opcionesUsuario.ts. Exporta dos arrays as const:

ConstanteÍtemsTiene icono
ALERGENOS_OPCIONES 14 (gluten, lácteos, huevo, frutos secos, pescado, marisco, soja, cacahuetes, mostaza, sésamo, apio, sulfitos, moluscos, altramuz) Sí — /alergenos/{id}.webp
DIETAS_OPCIONES 12 (vegetariano, vegano, keto, sin gluten, mediterránea, paleo, sin lactosa, halal, kosher, bajo en calorías, alto en proteínas, low carb) No

También exporta los tipos derivados IdAlergeno e IdDieta para tipar los arrays de selección en el backend.

8. Reglas de diseño aplicadas

  • Mobile-first, base 390 px. Sin NavBar inferior.
  • 100% paleta Cookr — sin colores hardcodeados (bg-brand, bg-muted, text-foreground…).
  • Sin bordes de 1px para seccionar — separador tonal con bg-border/50.
  • Chips con flex-wrap gap-2, fluyen en líneas naturales.
  • Animación Framer Motion scale(1.05) en activación, duration: 150ms.
  • Estado de selección con useState local — sin Zustand hasta conectar backend.
