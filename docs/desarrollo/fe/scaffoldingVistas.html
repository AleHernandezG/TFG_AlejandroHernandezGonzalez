Pages placeholder

Las tres rutas nuevas usan un Server Component mínimo estándar de Next.js App Router. No tienen 'use client' ni imports innecesarios — se sustituyen enteros cuando llegue el Stitch aprobado. 

// app/(main)/despensa/page.tsx (igual para /chat y /perfil)
export default function PaginaDespensa() {
  return (
    <main className="flex min-h-screen items-center justify-center">
      <p className="text-muted-foreground">Próximamente</p>
    </main>
  )
}
