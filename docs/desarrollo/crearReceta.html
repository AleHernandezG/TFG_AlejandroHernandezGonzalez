Algoritmo de detección de alérgenos

Función pura detectarAlergenos(nombres: string[]): string[] ubicada en features/recetas/utils/detectarAlergenos.ts. Sin dependencias externas. Devuelve un array de IDs únicos compatibles con ALERGENOS_OPCIONES.

Lógica

Para cada nombre de ingrediente recibido, busca coincidencias (substring bidireccional, case-insensitive) en el mapa estático de datosIngredientes.ts. Acumula los alérgenos de cada match en un Set para evitar duplicados. 

export function detectarAlergenos(nombres: string[]): string[] {
  const encontrados = new Set<string>()
  for (const nombre of nombres) {
    const norm = nombre.toLowerCase().trim()
    for (const ing of INGREDIENTES_COMUNES) {
      if (ing.nombre.toLowerCase().includes(norm) ||
          norm.includes(ing.nombre.toLowerCase())) {
        ing.alergenos.forEach(a => encontrados.add(a))
      }
    }
  }
  return Array.from(encontrados)
}

Foto automática — Pexels API

Si el usuario no sube foto al crear la receta, el backend llama a Pexels API para obtener una imagen representativa basada en el título. La URL se guarda en MongoDB junto a los créditos obligatorios. Decisión tomada frente a otras opciones (Unsplash, Cloudinary AI) — ver docs/desarrollo/estadoTareas.html · FOTO-001.

Flujo BE al publicar (Fase 5)

1
POST /api/recetas recibe los datos del formulario Si foto está vacío → continúa al paso 2. Si el usuario subió foto → imagenService.subirFoto(file) → Cloudinary, fotoFuente = 'usuario'
2
imagenService.buscarFotoPexels(titulo) GET https://api.pexels.com/v1/search?query={titulo}&per_page=1&orientation=landscape con header Authorization: PEXELS_API_KEY
3
Pexels devuelve el objeto foto — se extraen los campos necesarios foto = photos[0].src.large2x · fotoCredito.fotografo = photos[0].photographer · fotoCredito.urlFoto = photos[0].url · fotoCredito.urlPerfil = photos[0].photographer_url
4
Se guarda en MongoDB: fotoFuente = 'pexels' + fotoCredito = {...} Solo 1 llamada a Pexels en el momento de crear la receta. En cada render posterior se usa la URL ya guardada — sin llamadas externas adicionales.

Schema MongoDB — campos añadidos al modelo Receta

fotoFuente: 'usuario' | 'pexels' | 'cloudinary'   // default: 'usuario'
fotoCredito?: {
  fotografo: string      // nombre del fotógrafo en Pexels
  urlFoto:   string      // enlace a la foto en pexels.com (obligatorio en atribución)
  urlPerfil: string      // enlace al perfil del fotógrafo (obligatorio en atribución)
}

Créditos obligatorios — licencia Pexels

La licencia Pexels exige mostrar atribución cuando se usa su contenido. Se muestra discretamente bajo la foto en la vista de detalle.
