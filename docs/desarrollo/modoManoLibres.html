Descripción — HANDS-001 ✅ Sprint 5

El modo manos libres lee en voz alta los pasos de una receta usando la Web Speech API del navegador, avanzando automáticamente al siguiente paso al terminar de leer cada uno. La pantalla permanece encendida mientras está activo gracias a la Navigator Wake Lock API.

Flujo de usuario

Botón "Modo manos libres" → Lee paso 1 → onend → paso 2 → ... auto-avance → Fin o X detener

Controles disponibles

  • ← Anterior — salta al paso previo y lo lee desde el inicio
  • ⏸ Pausar / ▶ Reanudar — pausa/reanuda la síntesis de voz
  • → Siguiente — salta al siguiente paso sin esperar a que termine
  • ✕ Detener — cancela TTS, libera Wake Lock, resetea estado

Detalles de implementación

  • pasosRef y pasoActualRef como useRef — evita stale closure en utterance.onend
  • utterance.lang = 'es-ES' — voz en español
  • utterance.rate = 0.9 — velocidad ligeramente reducida para mejor comprensión
  • Auto-avance en utterance.onend — solo si hay más pasos
  • Cleanup en useEffect return — cancela TTS y libera Wake Lock al desmontar
  • Guard de soporte: setSoportado en useEffect para evitar SSR mismatch

Wake Lock

if ('wakeLock' in navigator) {
  wakeLockRef.current = await navigator.wakeLock.request('screen')
}
// Se libera en detener() y en cleanup de useEffect

El guard 'wakeLock' in navigator evita errores en navegadores que no lo soportan (Firefox). El try/catch absorbe el error si el usuario deniega el permiso.
