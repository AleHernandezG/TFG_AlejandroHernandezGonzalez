CHAT-HIST-001 — Historial de chats persistente

Sprint 5 · 2026-06-02 · ✅ Completado FE FIX z-index
Problema Solución chatStore SheetHistorialChat Fix z-index Flujo completo Archivos

Problema

El botón "Ver historial de chats" existía visualmente en headerChat.tsx pero no hacía nada. contenidoChat.tsx no pasaba onVerHistorial a HeaderChat, y no había ningún componente de historial ni persistencia implementada.

Adicionalmente, aunque se hubiera abierto un Sheet, este quedaba tapado por el contenedor del chat (z-[60]) porque el Sheet de shadcn/ui usa z-50 por defecto, que es menor.

Solución

Tres piezas que trabajan juntas:

  1. chatStore.ts reescrito con zustand persist — añade historial: ConversacionGuardada[] y tres acciones: guardar, restaurar, eliminar.
  2. SheetHistorialChat.tsx nuevo — componente Sheet que lista las conversaciones guardadas y expone las acciones del store.
  3. sheet.tsx — z-index bumpeado de z-50 a z-[70] en overlay y content para aparecer por encima del chat.

chatStore.ts — zustand persist

El store usa persist con partialize para guardar solo el historial en localStorage, nunca los mensajes en curso (evita almacenar imágenes base64 entre sesiones).

persist(
  (set, get) => ({ ... }),
  {
    name: 'cookr-chat',
    partialize: (state) => ({ historial: state.historial }),
  }
)

Nuevas acciones:

  • nuevaConversacion() — si hay mensajes de usuario, crea un ConversacionGuardada con id, fecha ISO, primer mensaje (80 chars), y mensajes sin imagen. Limita el historial a 20 entradas. Limpia el chat actual.
  • restaurarConversacion(id) — busca en historial y restaura los mensajes en el chat.
  • eliminarConversacion(id) — filtra el historial y elimina la entrada.

Por qué se eliminan las imágenes al guardar: las imágenes base64 pueden pesar varios MB. Guardarlas en localStorage por cada conversación agotaría rápidamente el límite de 5–10 MB del storage. La imagen es útil durante la sesión; en el historial basta con el texto.

mensajes: mensajes.map(({ imagen: _img, ...rest }) => rest)

SheetHistorialChat.tsx

Sheet lateral (side="right", sm:max-w-sm) con tres zonas:

  • Botón "Guardar y empezar nueva conversación" — solo visible cuando la conversación actual tiene mensajes del usuario. Llama a nuevaConversacion() y cierra el sheet.
  • Lista de conversaciones — cada entrada muestra el primer mensaje (line-clamp-1), la fecha relativa (Hoy / Ayer / dd MMM) y el número de mensajes. Al pulsar restaura la conversación y cierra el sheet.
  • Botón eliminar — visible al hacer hover sobre cada entrada (icono Trash2). Elimina sin confirmación.

Estado vacío: icono MessageSquare con texto "Aquí aparecerán tus conversaciones anteriores".

function formatearFecha(iso: string): string {
  const fecha = new Date(iso)
  const hoy = new Date()
  const ayer = new Date(hoy)
  ayer.setDate(hoy.getDate() - 1)
  if (fecha.toDateString() === hoy.toDateString()) return 'Hoy'
  if (fecha.toDateString() === ayer.toDateString()) return 'Ayer'
  return fecha.toLocaleDateString('es-ES', { day: 'numeric', month: 'short' })
}

Fix z-index — sheet.tsx

El contenedor del chat es fixed inset-0 z-[60]. El Sheet de shadcn/ui usaba z-50 tanto en el overlay como en el content — ambos inferiores a 60, por lo que el sheet quedaba invisiblemente detrás del chat.

Fix: cambiar las dos clases hardcodeadas en frontend/src/components/ui/sheet.tsx:

ElementoAntesDespués
SheetOverlayz-50z-[70]
SheetContentz-50z-[70]

Este cambio afecta a todos los Sheets de la app (despensa, historial, etc.), lo cual es correcto: cualquier Sheet debe aparecer por encima de cualquier overlay de navegación.

Flujo completo

  1. Usuario pulsa "Ver historial de chats" en el header → setHistorialAbierto(true) en contenidoChat.tsx
  2. Se renderiza <SheetHistorialChat abierto={true} /> — el Sheet aparece por encima del chat (z-[70] > z-[60])
  3. Si hay mensajes en curso → botón "Guardar y empezar nueva conversación" visible → nuevaConversacion() → persiste en localStorage → cierra sheet
  4. Para recuperar una sesión → tap en una entrada → restaurarConversacion(id) → mensajes vuelven al chat → sheet cierra
  5. Para borrar → hover + icono papelera → eliminarConversacion(id)
  6. El historial persiste entre recargas y sesiones del navegador
