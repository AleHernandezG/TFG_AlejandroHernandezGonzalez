NUTR-001 — Macros reales al publicar

Al publicar una receta, recetaRepository.crear() llama a calcularMacros() antes de guardar el documento. La función llama a la Edamam Nutrition Analysis API con los ingredientes y retorna { calorias, proteinas, carbos, grasas }. Sin claves configuradas retorna ceros (mismo comportamiento que antes).

⚠️ Requiere EDAMAM_APP_ID y EDAMAM_APP_KEY en backend/.env. Obtener en developer.edamam.com → Nutrition Analysis API (tier gratuito: 100 análisis/mes).
ArchivoCambio
backend/src/services/nutritionService.ts Nuevo. calcularMacros(ingredientes[]) → POST a Edamam con array de strings "200g tomate". Fallback a ceros en cualquier error.
backend/src/repositories/recetaRepository.ts En crear(): reemplazado macros: {calorias:0,...} por macros: await calcularMacros(datos.ingredientes). 
// nutritionService.ts — llamada Edamam
const ingr = ingredientes.map(i => `${i.cantidad}${i.unidad} ${i.nombre}`)
POST https://api.edamam.com/api/nutrition-details
  ?app_id=EDAMAM_APP_ID&app_key=EDAMAM_APP_KEY
Body: { ingr: ["200g pasta", "100ml nata", ...] }

// Respuesta mapeada:
{
  calorias:  Math.round(data.calories),
  proteinas: Math.round(data.totalNutrients.PROCNT?.quantity),
  carbos:    Math.round(data.totalNutrients.CHOCDF?.quantity),
  grasas:    Math.round(data.totalNutrients.FAT?.quantity)
}

INGR-003 — Open Food Facts como fallback de autocompletado

La Food Database API de Edamam requería plan de pago, por lo que se ha reemplazado con Open Food Facts, que es gratuita, sin tarjeta, y tiene más de 3 millones de productos. El endpoint de sugerencias devuelve un array de strings en español directamente.

Sin API key — gratis ilimitado. Límite recomendado: 15 peticiones/minuto por IP.
ArchivoCambio
backend/src/services/ingredientesService.ts Reemplazado endpoint Edamam Food DB por world.openfoodfacts.org/cgi/suggest.pl?tagtype=ingredients&term=<query>&lc=es. Timeout 3s, fallback a array vacío. 
GET https://world.openfoodfacts.org/cgi/suggest.pl
  ?tagtype=ingredients&term=tomate&lc=es
→ ["Tomate", "Tomate cherry", "Tomate triturado", ...]

NUTR-002 — USDA FoodData Central como fallback de macros

Edamam Nutrition Analysis tiene un límite de 100 llamadas/mes. Cuando falla o no está configurado, nutritionService.calcularMacros() intenta ahora con la USDA FoodData Central API (1.000 peticiones/hora con clave gratuita). La función busca cada ingrediente, escala por cantidad/unidad y suma los macros.

⚠️ Requiere USDA_API_KEY en backend/.env. Obtener gratis en api.data.gov sin tarjeta de crédito.
ArchivoCambio
backend/src/services/nutritionService.ts Añadida función calcularMacrosUSDA() con conversión de unidades (g, kg, ml, tsp, tbsp, taza, unidad). calcularMacros() prueba Edamam primero, USDA si falla, ceros si ninguno.
backend/.env Añadida variable USDA_API_KEY= (vacía por defecto, funciona sin ella devolviendo ceros). 
// Flujo calcularMacros():
1. Edamam disponible → llama Edamam (100/mes gratis)
2. Edamam falla/no configurado → llama USDA (1000/hora gratis)
3. Ambos fallan → devuelve { calorias:0, proteinas:0, carbos:0, grasas:0 }
