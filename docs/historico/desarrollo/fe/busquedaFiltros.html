Cómo funciona el debounce y los skeleton loaders

Se creó un hook genérico useDebounce que retrasa cualquier valor un número de milisegundos configurable. En los feeds se usa con 300 ms:

// hooks/useDebounce.ts
export function useDebounce<T>(value: T, delay: number): T {
  const [debounced, setDebounced] = useState<T>(value)
  useEffect(() => {
    const timer = setTimeout(() => setDebounced(value), delay)
    return () => clearTimeout(timer)
  }, [value, delay])
  return debounced
}

En cada feed se deriva el estado cargando de forma reactiva, sin ningún efecto extra:

const busquedaDebounciada = useDebounce(busqueda, 300)
const cargando = busqueda !== busquedaDebounciada  // true durante los 300 ms

Mientras cargando === true se renderizan tarjetas esqueleto (cajas grises pulsantes) en lugar del feed real. En cuanto el valor debounced se actualiza, desaparecen y aparecen los resultados filtrados.

Cómo funciona el DrawerFiltros

El componente DrawerFiltros (features/recetas/components/home/drawerFiltros.tsx) usa el primitivo Drawer de Vaul (panel deslizante desde abajo, con soporte de gesto táctil) que ya existía en components/ui/drawer.tsx.

Recibe tres props:

interface Props {
  filtros: FiltrosAvanzados     // estado actual del padre
  onChange: (f: FiltrosAvanzados) => void  // callback al aplicar
  children: React.ReactNode     // el botón trigger
}

El drawer mantiene una copia local de los filtros mientras está abierto. El padre no se entera de los cambios hasta que el usuario pulsa "Aplicar". Si pulsa "Limpiar", la copia local se resetea pero el padre tampoco cambia hasta aplicar. Esto evita que el feed se recalcule en cada chip pulsado dentro del drawer.

  • 14 chips de ALERGENOS_OPCIONES (config/opcionesUsuario.ts)
  • Cada chip muestra la imagen del alérgeno (webp en /public/alergenos/)
  • Semántica: seleccionar un alérgeno excluye recetas que lo contienen
  • Chips activos en rojo destructive para reforzar la exclusión

Flujo de estado entre componentes

Móvil — feedHome.tsx posee todo el estado:

feedHome.tsx → Posee: busqueda, filtrosAvanzados {dietas, alergenos, dificultad}. Calcula busquedaDebounciada y cargando.
BuscadorFiltros → Renderiza barra de búsqueda + botón "Filtros" en la misma fila. Sin chips inline.
DrawerFiltros → Copia local de filtros mientras está abierto. Al "Aplicar" llama onChange y feedHome recalcula postsFiltrados.

Escritorio — layoutHomePc.tsx posee el estado y lo distribuye:

layoutHomePc.tsx → Posee: busqueda, filtrosAvanzados. Pasa busqueda a HeaderHomePc y filtrosAvanzados también.
HeaderHomePc → Recibe busqueda + filtrosAvanzados. Renderiza buscador + botón "Filtros" con DrawerFiltros centrado en el header.
FeedHomePc → Recibe busqueda + filtrosAvanzados. Solo renderiza skeletons o el bento grid filtrado.
