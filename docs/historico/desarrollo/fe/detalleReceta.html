1. Resumen de la vista

La vista Detalle de Receta está disponible en la ruta dinámica /recetas/[id]. Presenta todos los datos de una receta: imagen hero, metadatos, ingredientes escalables, información nutricional, pasos de cocción, comentarios y un carrusel de recetas similares.

3. Tipos TypeScript (RecetaDetalle)

RecetaDetalle extiende PostFeed (tipo del feed) con los campos específicos del detalle. Los componentes consumen este tipo directamente para garantizar que en Fase 5 solo sea necesario cambiar la fuente de datos, no los componentes. 

export type Ingrediente = {
  nombre:   string
  cantidad: number
  unidad:   string
}

export type Comentario = {
  autorNombre: string
  avatarUrl:   string | null
  texto:       string
  fecha:       string  // ISO 8601
}

export type MacrosReceta = {
  calorias:  number
  proteinas: number
  carbos:    number
  grasas:    number
}

export type RecetaDetalle = PostFeed & {
  categorias:  string[]
  pasos:       string[]
  ingredientes: Ingrediente[]
  alergenos:   string[]    // ids exactos del map ALERGENOS
  macros:      MacrosReceta
  comentarios: Comentario[]
  similares:   PostFeed[]
  porciones:   number     // porciones base para escalar ingredientes
}

4. Componente ChipAlergeno

Componente reutilizable que renderiza un chip con icono WebP oficial y etiqueta para cualquiera de los 14 alérgenos del Reglamento UE 1169/2011.

Props

PropTipoDefaultDescripción
alergenoIdstring—ID del alérgeno. Si no existe en el mapa, no renderiza nada.
size'sm' | 'md''sm'sm para detalle receta · md para filtros y crear receta

IDs disponibles

gluten · crustaceos · huevo · pescado · cacahuetes · soja · lacteos · frutosSecos · apio · mostaza · sesamo · sulfitos · moluscos · altramuz

Uso

// Tamaño sm (detalle receta)
{receta.alergenos.map((id) => (
  <ChipAlergeno key={id} alergenoId={id} size="sm" />
))}

// Tamaño md (filtros / crear receta)
<ChipAlergeno alergenoId="gluten" size="md" />
Imágenes WebP: Los iconos están en public/alergenos/<id>.webp. Se sirven vía next/image con optimización automática. No se requiere configuración adicional en next.config.ts.

5. Componentes de la vista

5.1 DetalleRecetaCliente

Client Component orquestador. Mantiene el estado guardado compartido entre el hero y la barra de stats. Compone el layout mobile y desktop. 

type Props = { receta: RecetaDetalle }

const [guardado, setGuardado] = useState(receta.guardado)

5.2 HeroReceta

Hero full-width de ~45vh. Imagen next/image con object-cover. Gradiente inferior que disuelve la imagen en el fondo. Botones flotantes glassmorphism (ArrowLeft + Bookmark/BookmarkCheck).

PropTipoDescripción
imagenUrlstringURL de la imagen de la receta
titulostringAlt text de la imagen
guardadobooleanEstado del bookmark
onToggleGuardado() => voidCallback para toggle guardado

5.3 CabeceraReceta

Overlapping con el gradiente del hero (-mt-8 z-10). Contiene: título, chips categoría (Badge shadcn), chips alérgenos (ChipAlergeno), avatar + nombre + tiempo relativo del autor, barra de stats (Heart con Framer Motion, MessageCircle, Share2, Bookmark).

Estado local: liked + likes. El like activo usa fill-brand text-brand con animación scale(1.3) de Framer Motion.

5.4 TabsReceta

Tabs shadcn con sticky top-0 z-30. Dos pestañas:

  • Ingredientes: Ajustador de porciones (−/número/+) con useState. Las cantidades escalan proporcionalmente según el factor = porciones / porcionesBase. Lista con Checkbox shadcn. Link "Añadir a mi despensa" (no funcional — Sprint 6).
  • Nutrición: Grid 2×2 con Calorías, Proteínas, Carbohidratos, Grasas. Macros escalados con el mismo factor de porciones. Cards con bg-[var(--warm-bg)] rounded-2xl.

5.5 PasosReceta

Lista numerada de pasos. Badge numerado con bg-brand text-brand-foreground rounded-full. Separación tonal entre pasos alternos (sin border línea). Botón "Manos libres" con icono Headphones (no funcional — Sprint 8).

5.6 ComentariosReceta

Muestra hasta 3 comentarios preview: Avatar shadcn + nombre font-semibold + texto con line-clamp-2 + tiempo relativo. Botón "Ver todos los comentarios" (no funcional — pendiente Sprint 4).

5.7 CarruselSimilares

Embla Carousel horizontal con dragFree: true y 2.5 cards visibles (w-[calc(100%/2.5)]). Cada mini card: imagen rounded-2xl + título line-clamp-2 + avatar del autor.

  return <DetalleRecetaCliente receta={receta} />
