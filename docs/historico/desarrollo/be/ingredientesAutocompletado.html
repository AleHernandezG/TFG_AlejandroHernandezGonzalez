Cómo funciona — orden de búsqueda

El hook busca en 3 fuentes en orden. Si una fuente da suficientes resultados, no consulta las siguientes.

1
buscarIngredientes(query) — local, 0 ms

Filtra los 239 ingredientes de ingredientes.ts contra nombre y aliases[]. Instantáneo, sin red. Ejemplos: escribir "bacon" → encuentra Panceta; "chicken" → Pechuga de pollo.

2
buscarEnCustom(query) — Zustand persist, 0 ms

Busca en los ingredientes que el usuario añadió previamente (Fase 6). También instantáneo. Los resultados de 1 y 2 se combinan (sin duplicados por nombre) antes de decidir si hay suficientes.

3
ingredientesService.buscarEdamam(query) — red, 300 ms debounce

Solo se llama si los resultados de 1+2 son menos de 3. Actualmente devuelve [] (placeholder). En Fase 6 conecta con Edamam. El debounce evita llamadas en cada tecla.

💡 Con 239 ingredientes locales cubriendo las recetas comunes, el paso 3 prácticamente nunca se ejecutará en el uso diario. El sistema está preparado para escalar sin cambiar el componente.

El hook en código

export function useAutocompletadoIngredientes(query: string) {
  // estado local
  const [sugerencias, setSugerencias] = useState<DatoIngrediente[]>([])
  const buscarEnCustom = useIngredientesCustomStore(s => s.buscarEnCustom)

  useEffect(() => {
    clearTimeout(debounceRef.current)           // cancelar debounce anterior

    if (query.length < 2) { setSugerencias([]); return }

    // Paso 1 + 2: local + custom, sin red
    const locales   = buscarIngredientes(query)
    const custom    = buscarEnCustom(query)
    const combinados = [...locales, ...custom.filter(c => !locales.some(l => l.nombre === c.nombre))]

    if (combinados.length >= 3) {
      setSugerencias(combinados); return   // suficiente → no llama a Edamam
    }

    // Paso 3: Edamam con debounce 300 ms
    debounceRef.current = setTimeout(async () => {
      const externos = await ingredientesService.buscarEdamam(query)
      setSugerencias([...combinados, ...externos])
    }, 300)
  }, [query, buscarEnCustom])

  return { sugerencias, cargando, esFallback }
}

function handleNombreChange(idx, valor) {

  const resultados = buscarIngredientes(valor, 6)      // filtrado inline

Qué queda para Fase 6 (Edamam)

Fase 6

Toda la arquitectura está puesta. Para que Edamam funcione de verdad solo hace falta un único cambio en un único fichero: 

// src/services/ingredientesService.ts — solo cambiar esto:
buscarEdamam: async (query: string): Promise<DatoIngrediente[]> => {
  // FASE 6 — descomentar y mapear la respuesta de Edamam:
  // const res = await apiClient.get('/ingredientes/buscar', { params: { q: query } })
  // return res.data.map(mapEdamamToIngrediente)
  return []   ← borrar esta línea
}

El backend necesitará un endpoint GET /api/ingredientes/buscar?q= que llame a la Edamam Food Database API con EDAMAM_APP_ID y EDAMAM_APP_KEY.

Cuando el usuario seleccione un ingrediente de Edamam, se añade al store con useIngredientesCustomStore().añadir(ingrediente) para que la próxima vez aparezca sin red.

⚠️ El tier gratuito de Edamam Food Database permite 100 llamadas/mes. El debounce de 300 ms + el umbral de ≥3 resultados locales protegen de llamadas innecesarias — en la práctica, casi nunca se llegará a llamar a la API.
