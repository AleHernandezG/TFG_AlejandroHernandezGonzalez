DET-010 — Metadatos dinámicos en /recetas/[id] ✅ Completado

Problema original

La página app/(main)/recetas/[id]/page.tsx tenía metadatos estáticos:

export const metadata = {
  title: 'Detalle de receta — Cookr',
  description: 'Ingredientes, pasos y nutrición de la receta.',
}

Al compartir un enlace de receta en WhatsApp, Telegram o Twitter, la tarjeta de previsualización mostraba siempre el mismo título genérico en lugar del nombre real de la receta.

Solución implementada

FE Archivo: frontend/src/app/(main)/recetas/[id]/page.tsx

import type { Metadata } from 'next'

export async function generateMetadata({ params }: { params: { id: string } }): Promise<Metadata> {
  const detalle = await recetasService.obtenerPorId(params.id)
  if (!detalle) return { title: 'Receta — Cookr' }
  const { receta } = detalle
  return {
    title: `${receta.titulo} — Cookr`,
    description: `${receta.descripcion} · ${receta.tiempo} · ${receta.dificultad}`,
    openGraph: {
      title: receta.titulo,
      description: receta.descripcion,
      images: receta.imagenUrl ? [{ url: receta.imagenUrl }] : [],
      type: 'article',
    },
  }
}

Decisiones de diseño

  • Sin token en generateMetadata: getServerSession no está disponible en el contexto de generateMetadata (se ejecuta en un contexto separado del page component). La llamada se hace sin autenticación — los metadatos son públicos.
  • Fallback genérico: si obtenerPorId devuelve null (ID inválido o receta eliminada), se retorna { title: 'Receta — Cookr' } sin lanzar error.
  • Segunda llamada al BE: Next.js deduplica automáticamente las llamadas fetch con la misma URL en el mismo ciclo de renderizado. Sin embargo, recetasService usa Axios, no fetch nativo — por tanto sí hay una segunda petición. El impacto es mínimo (llamada rápida sin autenticación) y es el trade-off aceptable para tener og:image real.
  • og:image condicional: solo se incluye si receta.imagenUrl existe — algunas recetas antiguas pueden no tenerla.

Estructura del tipo RecetaDetalle

La propiedad receta dentro de RecetaDetalle es de tipo DatosReceta:

type DatosReceta = {
  titulo: string        // ← og:title
  descripcion: string   // ← og:description
  imagenUrl: string     // ← og:image
  tiempo: string        // "45 min"
  dificultad: DificultadReceta  // 'Fácil' | 'Media' | 'Difícil'
}

Flujo completo

Bot compartir (WhatsApp/Telegram) → GET /recetas/[id] → generateMetadata() → recetasService.obtenerPorId(id) → Metadata con og:title, og:image → Tarjeta con imagen real ✅
