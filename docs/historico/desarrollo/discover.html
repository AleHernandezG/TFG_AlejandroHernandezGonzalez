Resumen

Vista /discover — feed de descubrimiento global con búsqueda, filtros por categoría, tarjeta de evento destacado y grid de recetas trending. Diseño basado en el sistema editorial "The Digital Gourmet" del Stitch.

Sprint 4: implementación FE mock completa con datos locales en datosDiscover.ts. Toda la lógica de filtrado es local (sin petición al backend). La integración real con el backend está planificada para Fase 5.

Estado local — ContenidoDiscover

Esta vista no requiere Zustand. Todo el estado es local al componente ContenidoDiscover ya que es UI-only (sin persistencia entre sesiones en Sprint 4).

query: string Texto introducido en el input de búsqueda. Controlado directamente por el input.
queryDebounced: string Versión debounced de query (300 ms) via useDebounce hook reutilizado de hooks/useDebounce.ts. Es el valor usado para filtrar recetas, evita re-filtrar en cada tecla.
categoriaActiva: CategoriaDiscover Categoría seleccionada en los chips. Default: 'Todos'.
tabActiva: TabInspiracion Tab seleccionada en la sección Inspiración: 'nuevo' (default) o 'reciente'. En mock, 'reciente' simplemente invierte el array.
recetasFiltradas (memo) Calculado con useMemo. Depende de queryDebounced, categoriaActiva y tabActiva. No es estado, es derivado.
🔍

Lógica de filtrado

Todo el filtrado ocurre en el useMemo de ContenidoDiscover. Sin llamada al backend en Sprint 4.

const recetasFiltradas = useMemo(() => {
  let lista = RECETAS_DISCOVER_MOCK

  // 1. Filtro por categoría
  if (categoriaActiva !== 'Todos') {
    lista = lista.filter((r) => r.categoria === categoriaActiva)
  }

  // 2. Filtro por búsqueda (título + nombre de autor, case-insensitive)
  if (queryDebounced) {
    const q = queryDebounced.toLowerCase()
    lista = lista.filter(
      (r) => r.titulo.toLowerCase().includes(q) ||
             r.autorNombre.toLowerCase().includes(q)
    )
  }

  // 3. Ordenación por tab
  return tabActiva === 'reciente' ? [...lista].reverse() : lista
}, [queryDebounced, categoriaActiva, tabActiva])

Condiciones de renderizado

CondiciónRender

Flujo de usuario

1
Usuario llega a /discover. Ve el header editorial "Descubre lo que está trending?", los chips de categoría, la tarjeta del evento destacado de la semana y el grid de 6 recetas en 2 columnas.
2
Pulsa un chip de categoría (ej. "Pasta"). El grid se filtra instantáneamente mostrando solo las recetas de esa categoría con animación AnimatePresence.
3
Cambia el tab a "Reciente" en la sección Inspiración. El grid invierte el orden de las recetas.
4
Escribe en la barra de búsqueda. Tras 300 ms (debounce), el header cambia a logo simple "Cookr" y el grid muestra los resultados filtrados por título y autor.
5
Si no hay resultados: aparece el estado vacío con el término buscado resaltado en brand, botón "Limpiar búsqueda" y 4 chips de sugerencias populares.
6
Pulsa una tarjeta de receta → navega a /recetas/[id].
